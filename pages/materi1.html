Mengenal HTML

HTML (HyperText Markup Language) adalah bahasa dasar dalam membangun struktur sebuah halaman web. HTML menentukan elemen-elemen seperti teks, gambar, tautan, dan layout secara keseluruhan. Apabila kita menganggap bahwa web itu seperti badan kita maka HTML itu seperti tulang kita, html yang memberikan kita struktur utama.

Mengenal CSS

CSS (Cascading Style Sheets) digunakan untuk mempercantik tampilan website. Dengan CSS, kamu bisa mengatur warna, ukuran font, layout, animasi, dan banyak hal lainnya. Jika dalam tubuh manusia ibarat seperti penampilan manusia

Mengenal JavaScript

JavaScript adalah bahasa pemrograman yang membuat website menjadi interaktif dan dinamis. Misalnya: membuat tombol yang bisa diklik, animasi, hingga aplikasi berbasis web. Dalam tubuh manusia dapat diibaratkan seperti sistem saraf yang mengontrol gerakan pada manusia sehingga bisa berinteraksi

Mengenal Tailwind CSS

Tailwind CSS adalah framework CSS modern berbasis utility-class. Dengan Tailwind, kamu bisa membangun tampilan website yang indah tanpa menulis CSS dari nol. Dengan framework ini, maka tidak perlu lagi untuk pindah pindah file setiap kali mau mengembangkan program html dan css
