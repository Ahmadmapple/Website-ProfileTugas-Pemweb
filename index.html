Pengenalan HTML, CSS, JavaScript, dan Tailwind

HTML (HyperText Markup Language)

HTML adalah bahasa dasar untuk membuat struktur sebuah halaman web. Dengan HTML, kita menentukan elemen seperti judul, paragraf, gambar, tautan, tabel, dan lainnya.

CSS (Cascading Style Sheets)

CSS digunakan untuk mengatur tampilan dari elemen HTML seperti warna, font, tata letak, dan animasi agar website terlihat menarik dan responsif.

JavaScript (JS)

JavaScript berfungsi untuk menambahkan interaktivitas ke dalam website. Misalnya, menampilkan notifikasi, membuat animasi, dan memproses input pengguna secara dinamis.

Tailwind CSS

Tailwind CSS adalah framework utility-first yang membuat kita bisa mendesain langsung di dalam HTML menggunakan class siap pakai tanpa harus menulis CSS panjang.

Cara Membuat Website Sederhana

Membuat website sederhana tidak sulit! Cukup dengan HTML, CSS, dan sedikit JavaScript, kamu sudah bisa membuat halaman web yang menarik. Berikut langkah-langkah dasarnya 👇

Langkah 1 — Buat Struktur Dasar HTML

Buat file baru bernama index.html, lalu isi dengan struktur dasar HTML berikut:

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Website Sederhana</title>
</head>
<body>
    <h1>Halo Dunia!</h1>
    <p>Ini adalah website pertamaku.</p>
</body>
</html>

Langkah 2 — Tambahkan Gaya dengan CSS

Buat file style.css dan hubungkan ke HTML dengan tag <link>. Contoh sederhana:

body {
  background-color: #1e1e1e;
  color: white;
  font-family: Arial, sans-serif;
  text-align: center;
}

h1 {
  color: #ffcc00;
}

Langkah 3 — Tambahkan Interaktivitas dengan JavaScript

Buat file script.js dan tambahkan fungsi sederhana seperti alert:

document.addEventListener('DOMContentLoaded', () => {
  alert('Selamat datang di website sederhana!');
});

Langkah 4 — Jalankan Website

Buka file index.html menggunakan browser dan Website sederhana pertamamu sudah jadi :)

Kesan dan Pesan Belajar Web

Kesan

Belajar web memberikan pengalaman yang menyenangkan dan menantang. Awalnya terasa rumit karena banyak yang harus dipahami seperti struktur HTML, tampilan CSS, dan logika JavaScript. Tapi setelah paham alurnya, semuanya terasa seperti menyusun puzzle yang seru. Melihat hasil website yang bisa tampil di browser itu bikin rasa puas tersendiri!

Pesan

Jangan takut untuk memulai belajar web. Mulailah dari dasar, terus eksplor, dan jangan takut mencoba hal baru seperti framework modern (misalnya Tailwind atau React). Kuncinya adalah konsisten dan berani salah. Karena dari kesalahan itulah kita bisa berkembang jadi developer yang lebih baik.
